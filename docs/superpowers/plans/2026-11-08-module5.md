> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a comprehensible, source-audited Module 5 reviewer, flashcards, solo tests, and (if confirmed) Battle without disturbing prior content or progress.

**Architecture:** Keep the existing HTML notes parser, SubjectData merge, quiz builders, and Convex party bank. Module 5 content is isolated in new content files; existing modules, storage keys, and explicit midterm scope stay unchanged.

**Spec:** `docs/superpowers/specs/2026-11-08-module5-design.md`

## Global Constraints

- Use slides and ONLY Module 5 of updated class notes. Exclude the fake ebook. Do not claim required readings were verified.
- Preserve **18 guide answers (9/5/4)**, all source lists, image-only tables/figures, and exact source citations.
- Archived midterm remains **Modules 1–3**; no new finals exam/date. Old scores/IDs/banks are preserved.
- Every MTF prompt has a meaningful underline and a fitting replacement; accept reasonable equivalent answers without overmatching.
- Do not commit PDFs, `.claude/`, or unrelated package/portfolio changes. Build before each push.

## Review Focus

1. A fact inside a slide image must reach the actual reader, not just the audit: verify parsed tables/figure semantics and manually compare source renders.
2. Conflicting class-note shorthand must not become a misleading graded definition: audit uncertainty exclusions and inspect question answers.
3. Correct typed synonyms/numeric responses must grade correctly without accepting wrong units/bounds: fixture-based grading tests.
4. New content must not enter old midterms or reset saved banks: scope and identity tests.
5. M5 quotas must work server-side and in Battle setup, with old optional-field documents/defaults remaining valid: Convex boundary/draw tests plus browser selection check.
